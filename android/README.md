# Charkle for Android (`v1.5.0-alpha01` · Active Development)

Native **Android** client built with **Kotlin + Jetpack Compose (Material 3 Expressive)**, directly sharing the platform-agnostic Rust core ([`windows/crates/charkle-core`](../windows/crates/charkle-core)) via **UniFFI** for 100% lossless `/.charkle/` bidirectional sync parity with macOS, iOS/iPadOS, Windows, and Web.

## Architecture Overview

```text
android/
├── build.gradle.kts / settings.gradle.kts / gradle/libs.versions.toml
├── rust/
│   └── charkle-android-ffi/          # Standalone UniFFI 0.29 crate (cdylib -> libcharkle_android_ffi.so)
│                                     # Depends on ../../../windows/crates/charkle-core
│                                     # NEVER add to windows/Cargo.toml workspace members!
├── app/
│   └── src/main/
│       ├── AndroidManifest.xml       # MainActivity, ShareReceiveActivity, OAuthRedirect, QSTile, Glance Widget
│       ├── jniLibs/                  # Cross-compiled Rust .so (arm64-v8a / x86_64, generated by script)
│       └── java/
│           ├── uniffi/               # Generated UniFFI Kotlin bindings
│           └── com/charkle/android/
│               ├── core/             # CharkleRepository, AndroidSecretVaultImpl (Keystore), Models
│               ├── store/            # CharkleAppStore (StateFlow)
│               ├── designsystem/     # M3 Expressive Theme (Zone A neutral / Zone B artwork dynamic), icons
│               ├── ui/               # shell, gallery, inbox, detail, search, sidebar, capture, moodboard,
│               │                     # pinterest, settings
│               └── system/           # CharkleSyncWorker (WorkManager), QuickCaptureTileService, Glance Widget
└── scripts/
    ├── build-rust-android.sh         # cargo-ndk cross-compile + uniffi-bindgen Kotlin generation
    ├── verify-android.sh             # Rust unit tests + cross-compile + :app:assembleDebug + :app:testDebugUnitTest
    └── build-release-android.sh      # Slim Release .so + R8-minified & resource-shrunk Release APK
```

### Workspace Decoupling Guardrail
- `android/rust/charkle-android-ffi/` is an **independent Cargo package** referencing `windows/crates/charkle-core` by relative path. Do **not** add it to `windows/Cargo.toml` so Windows builds stay unaffected.
- Any helper added to `windows/crates/charkle-core` for Android must remain 100% OS-agnostic, warning-free, and covered by Rust unit tests.

## Prerequisites

- **JDK 17 or JDK 21** (`JAVA_HOME`)
- **Android SDK** (`minSdk = 26`, `targetSdk = 36`, `compileSdk = 37`) + **Android NDK** (`ANDROID_HOME`, `ANDROID_NDK_HOME`)
- **Rust 1.85+** with Android targets & `cargo-ndk`:
  ```bash
  rustup target add aarch64-linux-android x86_64-linux-android
  cargo install cargo-ndk
  ```

## Build & Verify Commands

Run from the repository root:

```bash
# 1. Cross-compile Rust core & regenerate UniFFI Kotlin bindings
#    (Add x86_64 for emulator testing: CHARKLE_ANDROID_ABIS="arm64-v8a x86_64")
./android/scripts/build-rust-android.sh

# 2. Full dev verification gate (Rust tests + .so/bindings + Kotlin unit tests + Debug APK)
./android/scripts/verify-android.sh

# 3. Slim R8-minified Release APK
#    Optional signing env vars:
#    CHARKLE_KEYSTORE_PATH / CHARKLE_KEYSTORE_PASS / CHARKLE_KEY_ALIAS / CHARKLE_KEY_PASS
./android/scripts/build-release-android.sh
```

> Local machine paths (`android/local.properties`) and signing keystores are gitignored — never commit them.
