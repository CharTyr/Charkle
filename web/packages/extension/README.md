# Charkle 灵感剪藏（Manifest V3 浏览器扩展）

零构建步骤、开箱即用的跨站灵感采集扩展，支持 **Chrome / Edge / Arc / Brave** 等所有 Chromium 内核浏览器，直连你的自托管 **Charkle Web** 服务。

## 安装方法

1. 打开浏览器的扩展管理页面：
   - Chrome / Arc：`chrome://extensions`
   - Edge：`edge://extensions`
   - Brave：`brave://extensions`
2. 打开右上角 **「开发者模式」** 开关。
3. 点击 **「加载已解压的扩展程序」**（或「加载解压缩的扩展」），选择本目录（`packages/extension/`，或从 Charkle Web「设置 → 插件与扩展」下载并解压后的文件夹）。
4. 建议在浏览器工具栏中将 **Charkle 灵感剪藏** 固定置顶，方便随时点击。

## 首次连接配置

1. 打开你的 Charkle Web 网页端，进入 **「设置 → 插件与扩展」**（或「账号与安全」），生成访问令牌。
2. 点击浏览器工具栏上的 Charkle 图标（或进入扩展「选项」页面），填写：
   - **服务地址**：例如 `http://127.0.0.1:3417` 或 `https://charkle.example.com`
   - **访问令牌**：粘贴刚刚生成的访问令牌
3. 点击 **「测试并保存」**，验证通过后会自动同步你的文件夹与情绪板列表。

## 核心能力

- **工具栏工作台（4 个采集模式）**：
  - **网页与截屏**：自动识别 X / Threads / Bluesky 推文、GitHub 仓库与普通网页书签，支持编辑标题与备注，并可一键 **「截取可见画面」** 上传原画 PNG。
  - **批量抓图**：自动扫描当前页面 `<img>`、`<picture>`、CSS 背景图与 OpenGraph 封面图（自动过滤 `< 64px` 追踪像素并按分辨率排序），支持 3 列画廊多选、**「全选大图」** 与后台并发批量入库。
  - **文字灵感**：自动填入页面当前划选文本，保存为带来源链接的 Markdown 灵感片段。
  - **色卡取色**：调用浏览器原生 `EyeDropper` 屏幕吸管（不支持时自动提供原生取色器与 `#HEX` 输入），一键入库 Charkle 色卡。
- **收藏目标切换**：工作台顶部实时切换 **收件箱 / 指定文件夹 / 当前情绪板**，设置自动持久化，同步作用于右键菜单、快捷键与跨站拖图。
- **5 项右键菜单**：
  - 收藏图片到 Charkle（扩展后台直接抓取原图，绕过网页跨域限制并记录来源页）
  - 收藏链接/推文/GitHub 到 Charkle
  - 收藏选中文字到 Charkle
  - 收藏当前网页到 Charkle
  - 截取当前页面到 Charkle
- **跨站拖图收藏悬浮舱**（默认开启，可在设置页关闭）：仅在外部网页拖拽图片时于右下角浮现极简液态玻璃胶囊，自动避开 Charkle Web 自身页面，松手即入库。
- **全局快捷键**：
  - `Alt + Shift + C`：一键快捷收藏当前网页
  - `Alt + Shift + K`：打开 Charkle 灵感剪藏工作台面板
